# 작은 동네 — 시민 생활 시뮬레이션

three.js로 만든 브라우저용 3D 생활 시뮬레이션입니다. 복셀 아트(MagicaVoxel 풍) 미니어처 디오라마로 꾸민 작은 동네에서 어른·초등학생·유치원생 시민과 반려동물(개·고양이·앵무새)이 각자의 욕구에 따라 스스로 할 일을 정하고 움직입니다. 심즈처럼 위에서 내려다보는 시점으로 관찰하다가, 원하면 직접 명령을 내릴 수도 있습니다.

빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

## 실행

- 브라우저에서 `index.html`을 바로 열거나, 정적 호스팅(GitHub Pages, Netlify, Vercel 등)에 올리면 됩니다.
- three.js는 jsDelivr CDN에서 import map으로 불러옵니다(`three@0.186.1`). 인터넷 연결이 필요합니다.
- 일부 브라우저는 `file://`에서 ES 모듈을 막을 수 있습니다. 그럴 때는 `npx serve .`처럼 간단한 로컬 서버로 여세요.

## 핵심 컨셉

**욕구 기반 자율 행동(Utility AI).** 모든 캐릭터는 시간이 지나면 줄어드는 욕구 수치(0–100)를 가지고 있습니다. 할 일이 끝나면 지금 할 수 있는 모든 행동에 점수를 매겨 가장 높은 것을 고릅니다.

```
점수 = (부족한 정도)² + 약간의 무작위 − 거리 × 가중치
```

부족한 정도를 제곱하기 때문에 급한 욕구일수록 강하게 우선됩니다. 무작위 값은 같은 상황에서도 매번 똑같이 움직이지 않게 해 줍니다. 시간대 보정(밤에는 잠을 우선함), 공원 이용 시간 제한, 개를 키우는 시민의 산책 선호 같은 규칙이 점수에 더해집니다.

**자리(spot) 예약.** 가구마다 사용할 수 있는 자리가 정해져 있습니다(소파 3석, 식탁 3석, 벤치 2석 등). 시민은 출발할 때 자리를 예약하므로 두 명이 같은 자리로 몰리지 않습니다.

**관절 단위 포즈 애니메이션.** 사람은 고관절·무릎·어깨·팔꿈치·가슴·머리를 각각 회전시켜 걷기, 앉기, 눕기, 쪼그려 앉기 같은 포즈를 만듭니다. 포즈 사이는 부드럽게 보간됩니다. 외부 3D 모델 파일 없이 기본 도형만으로 모든 캐릭터를 구성했습니다.

## 비주얼 컨셉: 복셀 미니어처 디오라마

캐릭터와 배경이 한 가지 그래픽 스타일로 읽히도록 "3D voxel art, MagicaVoxel 풍, 선명한 팔레트, 틸트시프트 미니어처 사진, 깔끔한 기하 도형"을 기준으로 삼았습니다.

- **각진 도형만 사용:** 사람·반려동물은 머리·몸통·팔다리·머리카락까지 전부 박스로 만들었고(관절 구조는 그대로), 나무는 각진 기둥 위에 잎 블록을 3단으로 쌓습니다. 공·원기둥·원뿔을 쓰던 소품(꽃, 가로등 머리, 분수, 그릇, 바퀴 등)은 `vSphere()`·`vCyl()`·`vCone()` 래퍼가 정육면체·사각기둥·피라미드로 바꿔 줍니다.
- **떠 있는 받침:** 끝없이 이어지는 땅 대신 잔디 윗면(1m 격자 무늬), 흙 단면, 바닥 돌로 된 디오라마 받침(`BASE`) 위에 동네가 놓여 있고, 배경은 하늘 대신 연회색 단색입니다. 도로는 받침 가장자리에서 끝나고 차는 거기서 나타나고 사라집니다.
- **색과 재질:** 모든 재질은 무광으로 통일하고 `vivid()`가 채도를 조금씩 올려 팔레트를 맞춥니다. 톤 매핑은 Neutral입니다.
- **카메라:** 화각을 27°로 좁히고 카메라를 멀리 두어 아이소메트릭에 가까운 구도로 내려다봅니다.
- **미니어처 효과:** 후처리(`TiltShader`, 가로·세로 2패스)로 화면 가운데 띠만 또렷하고 위아래가 흐려지는 틸트시프트를 걸고, 채도와 가장자리 어둡기를 살짝 더합니다. 멀리서 볼수록 흐림이 강해지고 가까이 가면 거의 사라집니다. 기본은 꺼져 있고(흐림이 눈에 부담될 수 있어서) 오른쪽 패널의 **🎞️ 미니어처 효과** 버튼으로 켤 수 있으며 설정은 브라우저에 저장됩니다. 소개창의 확대 뷰는 후처리 없이 그립니다.
- **도심 소품:** 보도를 따라 가로등이 서 있고(밤에 켜짐), 쓰레기통과 소화전이 있습니다.

## 시민

- 남자와 여자 두 종류이며, 둘 다 머리가 키의 약 1/5인 5등신 비율입니다(키 약 1.8m).
- 여자 시민은 어깨가 좁고 골반이 조금 넓으며, 키가 약 4% 작습니다. 머리 모양은 긴 생머리, 단발, 포니테일 중 하나이고, 절반쯤은 치마를 입습니다.
- 옷, 피부, 머리 색은 무작위로 정해집니다.
- 머리 위의 구슬은 전체 기분을 나타냅니다(초록 → 노랑 → 빨강).

### 욕구

| 욕구 | 줄어드는 이유 | 채우는 방법 |
|---|---|---|
| 배부름 | 시간 경과 | 식탁에서 식사 |
| 에너지 | 시간 경과, 밤에 더 빠름 | 침대에서 수면, 벤치 휴식 |
| 재미 | 시간 경과 | TV, 독서, 정원, 공원, 반려동물 |
| 청결 | 시간 경과, 정원 일 | 샤워 |
| 교류 | 시간 경과 | 다른 시민과 수다, 반려동물 |
| 지갑 | 시장에서 장보기(아주 천천히 자연 감소) | 회사에서 일하기 |

**나이.** 시민은 어른·초등학생·유치원생 중 하나입니다(추가할 때 고름). 아이는 몸이 작고 머리가 크며 지갑 욕구가 없습니다. 어른은 회사·시장에, 초등학생은 학교에, 유치원생은 유치원에 가고 오전에는 출근·등교가 거의 의무처럼 우선됩니다. 집마다 침대가 4개라 한 집에 4명까지 편히 삽니다.

### 행동

| 행동 | 장소 | 포즈 |
|---|---|---|
| 잠자기 | 침대(4개) | 누움 |
| 식사 | 식탁(3석) | 앉아서 손을 입으로 |
| TV 보기 | 소파(3석) | 앉음 |
| 독서 | 책장(2자리) | 서서 책을 듦 |
| 정원 가꾸기 | 앞마당 화단(2자리), 꾸미기 텃밭 | 허리 숙임 |
| 간식 사 먹기 | 꾸미기 자판기(1자리, 지갑 5 필요) | 서서 바라봄 |
| 그네 타기 | 꾸미기 그네(1자리) | 앉음 |
| 피크닉 | 꾸미기 피크닉 테이블(2자리) | 앉아서 식사 |
| 공사하기 | 꾸미기로 놓은 물건 앞 | 망치질 |
| 수업 듣기(초등학생) | 학교 책상(6자리, 9–15시) | 앉아서 필기 |
| 유치원에서 놀기(유치원생) | 유치원 탁자(6자리, 9–16시) | 앉음 |
| 블록 쌓기(유치원생) | 유치원 놀이 매트(3자리, 9–16시) | 쪼그려 앉아 손 움직임 |
| 샤워 | 샤워부스(1자리) | 팔을 머리 위로 |
| 수다 | 다른 시민 곁 | 마주 보고 손짓 |
| 반려동물과 놀기 | 반려동물 곁 | 쪼그려 쓰다듬기, 또는 손 뻗기(앵무새) |
| 공원 산책 | 공원 순환로 | 걷기 |
| 벤치 휴식 | 공원 벤치(3개 × 2석) | 앉음 |
| 분수 구경 | 분수 주변(4자리) | 서서 바라봄 |
| 일하기 | 회사 책상(6자리), 9–18시 | 앉아서 타이핑 |
| 장보기 | 시장 가판대(3곳 × 2자리), 8–20시 | 서서 고름 |

공원 시설은 낮(06–21시)에만 이용하고, 밤 10시 이후에는 잠을 강하게 우선합니다. 회사는 9–18시, 시장은 8–20시에만 열고, 출근 시간대에는 일하러 가고 싶은 마음이 더해집니다. 지갑이 15 아래면 장을 보지 못하고 일을 먼저 찾습니다. 장을 보면 지갑이 줄고 재미·배부름이 오릅니다. 할 일이 없으면 집 안을 돌아다닙니다.

## 반려동물

모든 반려동물에게는 주인 시민이 있고, 배부름·에너지·애정 욕구가 있습니다. 배가 고프면 밥그릇으로, 졸리면 잠자리로 스스로 갑니다.

- **개:** 주인이 산책하거나 외출하면 거의 항상 옆을 따라다닙니다. 혼자 있을 때는 집 안을 돌아다니거나 사람 곁에 다가가고, 신나면 꼬리를 빠르게 흔듭니다. 잠은 개 방석에서 잡니다.
- **고양이:** 대부분 제멋대로 움직이고, 주인을 따라가는 일은 드뭅니다. 꼬리를 천천히 흔들고, 쿠션에서 웅크려 잡니다.
- **앵무새:** 횃대에 앉아 고개를 갸웃거리다가 날개를 퍼덕이며 집과 공원 위를 날아다닙니다. 가끔 주인 어깨에 내려앉는데, 주인이 자거나 샤워하거나 다른 동물과 놀면 횃대로 돌아갑니다. 밥도 횃대에서 먹습니다.

시민은 재미나 교류가 부족할 때 반려동물에게 다가가 놀아 줍니다. 이때 반려동물은 멈춰서 시민 쪽을 바라보고, 애정 수치가 오릅니다.

## 동네 구성

- **받침:** 동네 전체는 98×70m 크기의 떠 있는 디오라마 받침 위에 있습니다. 보도에는 가로등, 쓰레기통, 소화전이 있습니다.
- **집 3채:** 각 16×12m 크기의 방에, 심즈처럼 낮게 잘린 벽이 뒤쪽과 왼쪽에만 있습니다. 침실(침대 4개), 부엌·식탁, 거실(소파·TV), 책장, 샤워부스, 반려동물 용품(개 방석, 고양이 쿠션, 밥그릇, 횃대)이 있고 앞마당에는 화단이 있습니다. 1호집은 도로 북쪽, 2호집은 남북 도로 서쪽, 3호집은 1호집 북쪽에 있으며 바닥·벽·소파·이불 색이 다릅니다. 시민마다 사는 집이 정해져 있어 자기 집 침대에서만 자고, 남의 집 물건은 덜 끌립니다. 새 시민은 가장 한산한 집으로 이사 오고, 반려동물은 주인의 집에서 삽니다. 처음 시작하면 1호집 4명, 2·3호집 2명씩 삽니다.
- **공원:** 집 동쪽에 있는 반지름 10m의 팔각형 공원입니다. 순환 산책로, 중앙 분수(물줄기 애니메이션), 벤치 3개, 꽃밭 4곳, 나무, 가로등 4개가 있습니다.
- **도로:** 집 남쪽을 지나는 동서 도로와, 집 서쪽의 남북 도로가 교차합니다. 보도, 점선 중앙선, 횡단보도 4곳이 있습니다.
- **회사:** 도로 남쪽 서편의 지붕 없는 사무실입니다. 책상 6개(모니터·키보드·의자), 안내 데스크, 부장 책상, 창문, 간판, 화분이 있습니다. 9–18시에만 엽니다.
- **시장:** 도로 남쪽 동편에 줄무늬 천막 가판대 3곳(과일, 꽃, 빵)이 있습니다. 8–20시에만 엽니다.
- **학교:** 3호집 동쪽의 지붕 없는 교실입니다. 칠판, 교탁, 학생 책상 6개, 국기 게양대가 있고 담임 선생님이 9–15시에 교탁 뒤에 서 있습니다. 초등학생만 씁니다.
- **유치원:** 2호집 북쪽의 파스텔색 교실입니다. 둥근 탁자 2개(각 3자리), 블록이 놓인 놀이 매트, 미끄럼틀이 있고 유치원 선생님이 9–16시에 있습니다. 유치원생만 씁니다.
- **장소별 NPC와 효과:** 장소마다 고유 인물이 있어 동네가 살아 있는 느낌을 줍니다.
  - 공원 **버스커**(11–20시): 분수 옆에서 기타를 치고 머리 위로 음표가 떠오릅니다. 9m 안에서 벤치·분수·산책 중인 시민은 재미가 1.6배로 차고 목록에 🎵가 붙습니다.
  - 공원 **관리인**(7–11시): 빗자루를 들고 공원 둘레를 2분 걷고 1분 쓸기를 반복하며, 옆을 지나는 시민에게 "쓰레기는 쓰레기통에!" 같은 말을 겁니다.
  - **우체부**(10–13시): 정류장에서 출발해 1·2·3호집 현관을 차례로 돌며 편지를 놓고 "편지 왔어요!"라고 외칩니다. 편지를 받은 집 주민은 교류가 6 오르고, 편지는 자정에 사라집니다.
  - **교통 경찰**(7:30–9:30, 17:30–19:30): 교차로 모퉁이에서 수신호를 합니다. 근무 중에는 교차로 9m 안의 차가 서행하고 가끔 "천천히 가세요!"를 듣습니다.
  - **정류장 할머니**(9–18시): 남쪽 정류장 벤치에 앉아 있다가 버스가 설 때마다 "드디어 왔네~" 같은 말을 하고, 지나가는 시민에게 밥은 먹었는지 묻습니다.
  - 움직이는 NPC의 위치는 게임 시각으로 계산되므로 호스트와 관전자가 같은 자리를 봅니다. 말풍선은 호스트가 띄워 모두에게 전달합니다.
- **NPC:** 시장의 가게 사장 3명, 회사의 안내 직원·부장, 학교 담임, 유치원 선생님은 시민이 아닌 고정 인물입니다. 욕구 없이 영업시간에만 그 자리에 있고(마우스를 올리면 이름이 보임), 시민이 장을 보러 오거나 출근해 자리에 앉으면 "싱싱한 과일 보고 가세요!" 같은 한마디를 말풍선으로 건넵니다. 생김새는 고정이라 모든 화면에서 같습니다.
- **버스 정류장:** 동서 도로 양쪽 보도에 하나씩 있습니다. 버스는 28–50초마다 한 대씩 나타나 자기 차선 정류장에 2.5초 정차한 뒤 떠납니다.
- **자동차:** 승용차·밴이 무작위 색으로 4–11초마다 도로 양끝에서 나타나 우측통행으로 지나갑니다(최대 9대). 앞차나 보행자·반려동물이 가까우면 속도를 줄이고, 보행자가 코앞이면 가끔 "빵빵!" 경적을 울립니다. 밤에는 전조등이 켜집니다. 차는 저장되지 않는 일회성 볼거리이고, 호스트가 움직여 관전자에게 전달합니다.
- **시간:** 1배속 기준 실제 1초가 게임 속 2분이라, 하루가 12분입니다. 해의 위치와 배경색이 변하고(낮, 노을, 밤), 밤에는 실내등과 가로등이 켜집니다.

## 조작

| 시민 또는 반려동물에 마우스 올리기 | 이름표 표시(평소에는 숨김, 선택한 캐릭터는 항상 표시) |

| 시민 선택 후 반려동물 클릭 | 그 반려동물과 놀러 감 |

| 🔨 꾸미기 (화면 왼쪽 아래) | 하단 팔레트를 열어 물건을 놓거나 치움 |

오른쪽 패널은 현황판입니다. 시간 속도(정지, 1×, 3×, 8×)와 미니어처 효과를 바꾸고, 시민(남/여)과 반려동물(개/고양이/앵무새)을 추가하고, 모든 캐릭터의 현재 행동과 기분을 한눈에 봅니다. 개별 캐릭터의 세부 정보와 조작은 왼쪽 소개창에 모여 있습니다. 반려동물을 추가하면 지금 선택한 시민이 주인이 되고, 선택한 시민이 없으면 무작위로 정해집니다.

**꾸미기(빌드 모드).** 화면 왼쪽 아래 **🔨 꾸미기** 버튼을 누르면 하단에 팔레트가 열립니다. 물건을 고르면 바닥 위에 반투명 미리보기가 따라다니고(0.5m 격자에 맞춤, 놓을 수 없는 곳은 빨갛게), 바닥을 클릭하면 놓입니다. **R** 키나 ⟳ 버튼으로 90°씩 돌리고, 🧹 치우기 모드에서 물건을 클릭하면 치웁니다(꾸미기로 놓은 것만). Esc는 선택 취소 → 팔레트 닫기 순서로 동작합니다.

- **시민이 짓는다:** 시민을 선택해 둔 채 놓으면 그 시민이 걸어가 4초 동안 망치질을 하고 완성합니다(그동안 🚧 공사 중 표시). 완성한 시민은 재미가 4 오릅니다. 다른 일로 끊기거나 호스트가 바뀌어도 물건은 완성됩니다. 시민을 선택하지 않으면 바로 놓입니다.
- **놓을 수 없는 곳:** 받침 밖, 도로 위, 건물 바닥 안, 분수 자리, 다른 물건과 겹치는 자리. 보도블록 길만 다른 물건과 겹칠 수 있습니다.
- **물건 16종:** 길·조명(보도블록, 가로등), 가구(벤치, 피크닉 테이블, 그네, 자판기), 자연(나무, 벚나무, 덤불, 화단, 텃밭, 연못, 바위), 소품(울타리, 우체통, 쓰레기통). 가로등은 밤에 켜지고, 벤치·피크닉 테이블·그네·자판기·텃밭은 시민이 실제로 씁니다(벤치 휴식, 피크닉, 그네 타기, 간식 사 먹기, 텃밭 가꾸기). 쓸 수 있는 물건은 선택한 시민에게 클릭으로 시킬 수도 있습니다.
- **함께 보기·저장:** 관전자가 놓거나 치운 것은 호스트가 처리해 모두에게 반영되고, 놓은 물건은 스냅샷에 저장되어 다음에도 그대로 있습니다. 동네 초기화를 하면 함께 사라집니다.

**소개창.** 시민이나 반려동물을 클릭하면 화면 왼쪽에 소개창이 열립니다. 모바일처럼 폭이 좁은 화면(760px 이하)에서는 아래 현황 패널의 맨 위에 끼워져 열리고, 그 아래로 시민·반려동물 목록이 이어져 함께 스크롤됩니다. 시민의 소개창은 세 탭으로 나뉩니다.

- **소개**: 확대 뷰(같은 3D 장면을 얼굴 앞에 둔 카메라로 한 번 더 그린 것이라 포즈와 움직임이 실시간으로 이어집니다), 남길 말 말풍선, 인사말, 현재 상태(기분과 행동), 욕구 게이지, 카메라 따라가기·하던 일 멈추기 버튼.
- **방명록**: 이 시민에게 남겨진 글 목록과 작성 폼. 작성자는 동네 시민 이름 중에서 고릅니다. 최신 글이 위에 오고 시민당 50개까지 남습니다. 글마다 ✕로 지울 수 있고, **방명록 모두 지우기** 버튼(4초 안에 두 번 누름)으로 전부 지울 수 있습니다. 관전자가 지워도 호스트가 처리해 모두에게 반영됩니다.
- **설정**: 이름, 인사말, 남길 말 수정 폼과 **이 시민 삭제** 버튼(4초 안에 두 번 눌러야 실행). 삭제된 시민의 반려동물은 주인 없이 동네에 남습니다.

반려동물은 소개 탭만 있고 확대 뷰·상태·욕구·주인 정보와 삭제 버튼을 보여 줍니다. 창의 ✕나 배경 클릭, Esc로 선택을 풀면 사라집니다. 함께 보기에서는 남길 말과 방명록이 모두에게 동기화되고, 자동 저장에도 포함됩니다.

**이름과 인사말.** 시민을 추가할 때 이름과 인사말을 정할 수 있습니다(이름을 비우면 자동으로 정해집니다). 소개창 설정 탭에서 이름과 인사말을 언제든 바꿀 수 있습니다. 시민 둘이 만나 수다를 시작하면 각자의 인사말이 말풍선으로 뜹니다. 관전자가 바꾼 이름·인사말도 호스트와 모든 관전자에게 반영되고, 말풍선도 같이 보입니다.

## 함께 보기 (모두가 같은 동네를 봅니다)

같은 주소를 연 사람은 누구나 **같은 동네**를 봅니다. 방을 열거나 링크를 공유할 필요가 없습니다.

- 페이지를 가장 먼저 연 브라우저가 자동으로 **호스트**가 되어 시뮬레이션을 돌립니다. 화면 왼쪽 위 표시가 "이 화면이 호스트"로 바뀝니다.
- 그 뒤에 연 브라우저는 자동으로 **관전자**가 되어 호스트와 똑같은 동네를 봅니다. 접속 즉시 현재 상태를 이어서 보고, 시민 선택·가구 클릭 명령·시민/반려동물 추가·이름/인사말 수정·속도 변경도 할 수 있습니다. 명령은 호스트에서 실행되어 모두에게 반영됩니다.
- 호스트가 탭을 닫으면 남은 사람 중 한 명이 자동으로 호스트를 이어받습니다. 시민들의 위치와 욕구는 그대로 이어지고, 하던 행동만 새로 정합니다.
- 연결 서버에 닿지 못하면 "혼자 보기"로 열립니다. 새로고침하면 다시 시도합니다.
- 따로 떨어진 동네를 쓰고 싶으면 주소 뒤에 `?room=이름`을 붙이면 됩니다. 같은 `room` 값을 연 사람끼리만 같은 동네를 봅니다.

**동작 방식**

- 서버 없이 브라우저끼리 WebRTC(PeerJS)로 직접 연결됩니다. 연결 상대를 찾는 데만 PeerJS 공개 서버(`0.peerjs.com`)를 씁니다.
- 호스트는 정해진 방 id를 PeerJS 서버에 등록합니다. 이미 등록돼 있으면(`unavailable-id`) 관전자로 합류합니다. 호스트가 사라지면 관전자들이 짧은 무작위 지연 뒤 다시 방 id를 차지하려 하고, 성공한 한 명이 이어받습니다(`takeOverState`).
- 호스트는 초당 10번 모든 시민·반려동물의 위치, 방향, 상태, 욕구와 시뮬레이션 시각을 보냅니다(`state`). 접속 시에는 시민·반려동물 정의(이름, 외형, 주인, 인사말)를 먼저 보냅니다(`init`).
- 관전자는 받은 위치로 부드럽게 보간하고, 걷기·포즈 애니메이션만 자기 화면에서 계산합니다(`presentViewer`).
- 관전자의 명령은 `cmd` 메시지로 호스트에 전달되고, 호스트가 검증·실행한 뒤 결과 토스트를 돌려줍니다. 인사말 말풍선은 호스트가 `say` 메시지로 모두에게 보냅니다.

**제약**

- 호스트가 다른 탭으로 오래 전환하면(브라우저가 애니메이션을 멈춤) 시뮬레이션이 멈추고 관전자도 멈춥니다. 탭을 닫으면 다른 사람이 이어받지만, 전환만 한 경우는 이어받지 않습니다.
- 무료 공개 PeerJS 서버라 가끔 느리거나 끊길 수 있습니다.
- 브라우저끼리 직접 연결하므로 휴대폰 통신망, 회사 방화벽처럼 NAT가 엄격한 환경에서는 호스트에 연결되지 않을 수 있습니다. 10초 안에 연결이 안 열리는 일이 두 번 반복되면 자동으로 **혼자 보기**로 전환되어 저장본 또는 기본 주민으로 동네를 엽니다. 이런 환경까지 지원하려면 TURN 중계 서버가 필요합니다.
- **TURN 붙이기(Metered, 월 500MB 무료, 카드 불필요):** Metered 대시보드의 TURN 자격증명(서버 주소, username, credential)을 `index.html`의 `TURN_STATIC`에 넣습니다. HTML에 그대로 노출되므로 무료 한도 안의 데모 용도에 적합합니다.
- **TURN 붙이기(Cloudflare Realtime TURN, 월 1,000GB 무료, 결제수단 등록 필요):** Cloudflare 대시보드에서 TURN 키를 만들고, `turn-worker.js`를 Cloudflare Worker로 배포해 키 ID와 API 토큰을 Worker 비밀 변수로 넣습니다. 그 Worker 주소를 `index.html`의 `TURN_ENDPOINT`에 적으면 페이지가 시작할 때 6시간짜리 임시 자격증명을 받아 STUN과 함께 씁니다. 토큰은 브라우저에 노출되지 않습니다. 발급에 실패하면 STUN만으로 진행합니다. 중계가 켜지면 왼쪽 위 상태에 "중계 켜짐"이 붙습니다.
- 호스트 자리는 하나뿐이므로, 같은 `room`을 쓰는 모든 사람이 전 세계적으로 하나의 동네를 공유합니다.
- 나무 잎 색, 책 색 같은 장식 요소는 각자 브라우저에서 무작위로 정해지므로 화면마다 조금 다를 수 있습니다. 시민·반려동물의 움직임은 동일합니다.

## 저장과 복원

동네의 정본은 서버(`town-worker.js`, Cloudflare Workers + KV)에 두고, 브라우저 저장소(localStorage)는 예비로 씁니다.

- **서버 저장:** 호스트(또는 혼자 보기)가 3분마다, 시민·반려동물 추가·수정·삭제·방명록 직후(10초에 1회로 묶음), 탭을 숨기거나 닫을 때 스냅샷을 서버에 올립니다. 관전자는 올리지 않습니다. 서버는 더 오래된 스냅샷으로 덮어쓰는 요청을 거부합니다.
- **복원:** 페이지를 열면 서버 스냅샷을 먼저 받아 두고, 호스트가 되는 순간 서버본과 브라우저본 중 더 최신 것으로 동네를 이어서 시작합니다. 위치·욕구·시각·이름·남길 말·방명록이 그대로 이어지고, 하던 행동만 새로 정합니다. 둘 다 없으면 기본 주민 10명(어른 7명, 초등학생 2명, 유치원생 1명)과 반려동물 5마리로 시작합니다.
- **서버가 없거나 실패하면** 브라우저 저장소만 쓰며, 패널 아래 상태 문구에 표시됩니다.
- 탭을 닫을 때 동네가 멈추는 경우(이 탭이 호스트인데 보는 사람이 없거나, 혼자 보기)에만 브라우저의 기본 확인창이 뜹니다.
- 패널의 **동네 초기화**를 두 번 누르면 저장본을 지우고 처음부터 시작하며, 초기화된 동네가 즉시 서버에 올라갑니다.
- 아무도 보고 있지 않는 동안에는 시간이 흐르지 않습니다.

**서버 설정(Cloudflare, 카드 불필요)**

1. Storage & databases → KV → Create namespace: `citizen-town`
2. Workers & Pages → Create → Worker → `town-worker.js` 내용 붙여 넣고 Deploy
3. Worker → Settings → Bindings → KV namespace: 변수 이름 `TOWN`, 네임스페이스 `citizen-town`
4. (선택) Variables에 `ALLOW_ORIGIN`(허용 출처), `TOWN_KEY`(쓰기 비밀키) 추가
5. Worker 주소를 `index.html`의 `TOWN_ENDPOINT`에, 비밀키를 썼다면 `TOWN_KEY`에 넣습니다.

쓰기 주소는 공개되므로 누구나 동네를 덮어쓸 수 있습니다. `TOWN_KEY`로 가벼운 보호가 되지만 HTML에 노출되는 값이라 완전하지는 않습니다. 무료 한도는 KV 쓰기 하루 1,000회이며 위 주기면 충분합니다.

## 코드 구조

모든 코드는 `index.html` 안의 모듈 스크립트 하나에 있습니다.

| 영역 | 내용 |
|---|---|
| `ACTS` | 행동 정의: 표시 이름, 이모지, 포즈, 채우는 욕구, 초당 회복량(`gains`), 최대 지속 시간 |
| `vivid()` · `mat()` · `vSphere()` · `vCyl()` · `vCone()` | 채도 보정 무광 재질과, 둥근 도형을 각진 복셀 도형으로 바꾸는 래퍼 |
| `BASE` · `ground` · `tree()` | 디오라마 받침(잔디 격자·흙·돌)과 복셀 나무 |
| `addObject()` | 가구와 사용 자리(spot) 등록, 클릭 판정 연결 |
| `buildPerson()` | 성별에 따른 사람 모델 생성(관절 그룹 계층) |
| `Citizen` | 욕구 감소, 행동 선택(`decide`), 이동, 포즈 애니메이션 |
| `buildDog()` · `buildCat()` · `buildParrot()` | 반려동물 모델 |
| `Pet` | 반려동물 상태 머신(돌아다님, 따라감, 식사, 수면, 비행, 어깨 위 등) |
| `buildHouse()` · `HOUSES` | 집 한 채(바닥·벽·가구·반려동물 용품)를 원점 기준으로 짓고, 가구 자리에 집 번호를 기록 |
| `ROADS` · `OFFICE` · `MARKET` · `SCHOOL` · `KINDER` · `BUS_STOPS` | 도로·횡단보도, 회사(책상 6개), 시장(가판대 3곳), 학교(책상 6개), 유치원(탁자·매트), 정류장 생성. `placeTag()`로 장소 이름표 |
| `AGES` · `needKeys()` | 나이별 몸 크기·머리 비율과 욕구 목록(아이는 지갑 없음). `ACTS[*].age`로 장소 이용 나이 제한 |
| `BUILD_KINDS` · `builds` · `placeResult()` · `completeBuild()` · `removeBuild()` · `syncBuilds()` | 꾸미기 물건 정의와 놓기·완성·치우기, 관전자·저장 동기화. 하단 팔레트 UI(`setBuildMode`, `moveGhost`, `buildClick`) |
| `Npc` · `npcGreet()` · `NPC_PLACE` · `busker` · `police` | 상인·회사 직원·선생님·버스커·관리인·우체부·경찰·할머니 NPC(시각 기반 이동 `motion`, 지나가는 시민에게 말 걸기 `passLines`, 소품 `build`)(고정 위치, 영업시간 표시, 인사 말풍선과 관전자 전달) |
| `Car` · `updateCars()` · `spawnBus()` | 자동차·버스 생성, 주행·감속·경적·정류장 정차, 관전자 동기화(`applyCars`) |
| `updateSky()` | 시간대에 따른 조명, 배경색, 가로등 |
| `TiltShader` · `composer` · `fxOn` | 틸트시프트·채도·비네팅 후처리와 켜기/끄기 저장 |
| UI 영역 | 패널 목록과 욕구 게이지, 클릭 판정(레이캐스트), 카메라 이동 |
| Multiplayer 영역 | 호스트 차지(`claimHost`), 관전 합류(`joinAsViewer`), 호스트 이어받기(`takeOverState`), 상태 직렬화(`netState`/`applyNet`), 원격 명령 처리(`handleCommand`) |
| Persistence 영역 | 스냅샷 저장·복원(`saveSnapshot`/`uploadSnapshot`/`fetchServerSnapshot`/`restoreSnapshot`), 동네 초기화(`resetTown`), 종료 확인 |

밸런스는 `DECAY`(욕구 감소 속도), `ACTS[*].gains`(회복량), `MIN_PER_SEC`(시간 흐름)를 바꿔 조절할 수 있습니다.

## 앞으로 붙일 수 있는 것

- 시민 사이의 관계 수치(친구, 연인)와 그에 따른 행동 변화
- 직업과 출퇴근, 여러 채의 집이 있는 동네
- 다른 집 반려동물끼리 만나 노는 상호작용
- 공원 이벤트(장터, 버스킹)
- 대화 내용을 LLM으로 생성해 말풍선으로 보여 주기
- 상태 저장과 불러오기(localStorage)
