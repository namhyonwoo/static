# 작은 동네 — 시민 생활 시뮬레이션

three.js로 만든 브라우저용 3D 생활 시뮬레이션입니다. 집과 공원이 있는 작은 동네에서 남녀 시민과 반려동물(개·고양이·앵무새)이 각자의 욕구에 따라 스스로 할 일을 정하고 움직입니다. 심즈처럼 위에서 내려다보는 시점으로 관찰하다가, 원하면 직접 명령을 내릴 수도 있습니다.

빌드 과정 없이 `index.html` 파일 하나로 동작합니다.

## 실행

- 브라우저에서 `index.html`을 바로 열거나, 정적 호스팅(GitHub Pages, Netlify, Vercel 등)에 올리면 됩니다.
- three.js는 jsDelivr CDN에서 import map으로 불러옵니다(`three@0.186.1`). 인터넷 연결이 필요합니다.
- 일부 브라우저는 `file://`에서 ES 모듈을 막을 수 있습니다. 그럴 때는 `npx serve .`처럼 간단한 로컬 서버로 여세요.

## 핵심 컨셉

**욕구 기반 자율 행동(Utility AI).** 모든 캐릭터는 시간이 지나면 줄어드는 욕구 수치(0–100)를 가지고 있습니다. 할 일이 끝나면 지금 할 수 있는 모든 행동에 점수를 매겨 가장 높은 것을 고릅니다.

```
점수 = (부족한 정도)² + 약간의 무작위 − 거리 × 가중치
```

부족한 정도를 제곱하기 때문에 급한 욕구일수록 강하게 우선됩니다. 무작위 값은 같은 상황에서도 매번 똑같이 움직이지 않게 해 줍니다. 시간대 보정(밤에는 잠을 우선함), 공원 이용 시간 제한, 개를 키우는 시민의 산책 선호 같은 규칙이 점수에 더해집니다.

**자리(spot) 예약.** 가구마다 사용할 수 있는 자리가 정해져 있습니다(소파 3석, 식탁 3석, 벤치 2석 등). 시민은 출발할 때 자리를 예약하므로 두 명이 같은 자리로 몰리지 않습니다.

**관절 단위 포즈 애니메이션.** 사람은 고관절·무릎·어깨·팔꿈치·가슴·머리를 각각 회전시켜 걷기, 앉기, 눕기, 쪼그려 앉기 같은 포즈를 만듭니다. 포즈 사이는 부드럽게 보간됩니다. 외부 3D 모델 파일 없이 기본 도형만으로 모든 캐릭터를 구성했습니다.

## 시민

- 남자와 여자 두 종류이며, 둘 다 머리가 키의 약 1/5인 5등신 비율입니다(키 약 1.8m).
- 여자 시민은 어깨가 좁고 골반이 조금 넓으며, 키가 약 4% 작습니다. 머리 모양은 긴 생머리, 단발, 포니테일 중 하나이고, 절반쯤은 치마를 입습니다.
- 옷, 피부, 머리 색은 무작위로 정해집니다.
- 머리 위의 구슬은 전체 기분을 나타냅니다(초록 → 노랑 → 빨강).

### 욕구

| 욕구 | 줄어드는 이유 | 채우는 방법 |
|---|---|---|
| 배부름 | 시간 경과 | 식탁에서 식사 |
| 에너지 | 시간 경과, 밤에 더 빠름 | 침대에서 수면, 벤치 휴식 |
| 재미 | 시간 경과 | TV, 독서, 정원, 공원, 반려동물 |
| 청결 | 시간 경과, 정원 일 | 샤워 |
| 교류 | 시간 경과 | 다른 시민과 수다, 반려동물 |

### 행동

| 행동 | 장소 | 포즈 |
|---|---|---|
| 잠자기 | 침대(4개) | 누움 |
| 식사 | 식탁(3석) | 앉아서 손을 입으로 |
| TV 보기 | 소파(3석) | 앉음 |
| 독서 | 책장(2자리) | 서서 책을 듦 |
| 정원 가꾸기 | 앞마당 화단(2자리) | 허리 숙임 |
| 샤워 | 샤워부스(1자리) | 팔을 머리 위로 |
| 수다 | 다른 시민 곁 | 마주 보고 손짓 |
| 반려동물과 놀기 | 반려동물 곁 | 쪼그려 쓰다듬기, 또는 손 뻗기(앵무새) |
| 공원 산책 | 공원 순환로 | 걷기 |
| 벤치 휴식 | 공원 벤치(3개 × 2석) | 앉음 |
| 분수 구경 | 분수 주변(4자리) | 서서 바라봄 |

공원 시설은 낮(06–21시)에만 이용하고, 밤 10시 이후에는 잠을 강하게 우선합니다. 할 일이 없으면 집 안을 돌아다닙니다.

## 반려동물

모든 반려동물에게는 주인 시민이 있고, 배부름·에너지·애정 욕구가 있습니다. 배가 고프면 밥그릇으로, 졸리면 잠자리로 스스로 갑니다.

- **개:** 주인이 산책하거나 외출하면 거의 항상 옆을 따라다닙니다. 혼자 있을 때는 집 안을 돌아다니거나 사람 곁에 다가가고, 신나면 꼬리를 빠르게 흔듭니다. 잠은 개 방석에서 잡니다.
- **고양이:** 대부분 제멋대로 움직이고, 주인을 따라가는 일은 드뭅니다. 꼬리를 천천히 흔들고, 쿠션에서 웅크려 잡니다.
- **앵무새:** 횃대에 앉아 고개를 갸웃거리다가 날개를 퍼덕이며 집과 공원 위를 날아다닙니다. 가끔 주인 어깨에 내려앉는데, 주인이 자거나 샤워하거나 다른 동물과 놀면 횃대로 돌아갑니다. 밥도 횃대에서 먹습니다.

시민은 재미나 교류가 부족할 때 반려동물에게 다가가 놀아 줍니다. 이때 반려동물은 멈춰서 시민 쪽을 바라보고, 애정 수치가 오릅니다.

## 동네 구성

- **집:** 16×12m 크기의 방에, 심즈처럼 낮게 잘린 벽이 뒤쪽과 왼쪽에만 있습니다. 침실(침대 4개), 부엌·식탁, 거실(소파·TV), 책장, 샤워부스, 반려동물 용품(개 방석, 고양이 쿠션, 밥그릇, 횃대)이 있습니다. 앞마당에는 화단이 있습니다.
- **공원:** 집 동쪽에 있는 반지름 10m의 원형 공원입니다. 순환 산책로, 중앙 분수(물줄기 애니메이션), 벤치 3개, 꽃밭 4곳, 나무, 가로등 4개가 있습니다.
- **시간:** 1배속 기준 실제 1초가 게임 속 2분이라, 하루가 12분입니다. 해의 위치와 하늘색이 변하고(낮, 노을, 밤), 밤에는 실내등과 가로등이 켜집니다.

## 조작

| 동작 | 결과 |
|---|---|
| 시민 또는 반려동물 클릭 | 선택하고 상태 패널 표시 |
| 시민 선택 후 가구 클릭 | 그 가구를 사용하러 감 |
| 시민 선택 후 반려동물 클릭 | 그 반려동물과 놀러 감 |
| 시민 선택 후 바닥 클릭 | 그 위치로 걸어감 |
| 드래그 / 휠 | 시점 회전 / 확대·축소 |
| 전체 · 집 · 공원 버튼 | 카메라를 해당 위치로 이동 |
| Esc | 선택 해제 |

오른쪽 패널에서는 시간 속도(정지, 1×, 3×, 8×)를 바꾸고, 시민(남/여)과 반려동물(개/고양이/앵무새)을 추가하고, 카메라가 선택한 캐릭터를 따라가게 할 수 있습니다. 반려동물을 추가하면 지금 선택한 시민이 주인이 되고, 선택한 시민이 없으면 무작위로 정해집니다.

## 코드 구조

모든 코드는 `index.html` 안의 모듈 스크립트 하나에 있습니다.

| 영역 | 내용 |
|---|---|
| `ACTS` | 행동 정의: 표시 이름, 이모지, 포즈, 채우는 욕구, 초당 회복량(`gains`), 최대 지속 시간 |
| `addObject()` | 가구와 사용 자리(spot) 등록, 클릭 판정 연결 |
| `buildPerson()` | 성별에 따른 사람 모델 생성(관절 그룹 계층) |
| `Citizen` | 욕구 감소, 행동 선택(`decide`), 이동, 포즈 애니메이션 |
| `buildDog()` · `buildCat()` · `buildParrot()` | 반려동물 모델 |
| `Pet` | 반려동물 상태 머신(돌아다님, 따라감, 식사, 수면, 비행, 어깨 위 등) |
| `updateSky()` | 시간대에 따른 조명, 하늘색, 가로등 |
| UI 영역 | 패널 목록과 욕구 게이지, 클릭 판정(레이캐스트), 카메라 이동 |

밸런스는 `DECAY`(욕구 감소 속도), `ACTS[*].gains`(회복량), `MIN_PER_SEC`(시간 흐름)를 바꿔 조절할 수 있습니다.

## 앞으로 붙일 수 있는 것

- 시민 사이의 관계 수치(친구, 연인)와 그에 따른 행동 변화
- 직업과 출퇴근, 여러 채의 집이 있는 동네
- 다른 집 반려동물끼리 만나 노는 상호작용
- 공원 이벤트(장터, 버스킹)
- 대화 내용을 LLM으로 생성해 말풍선으로 보여 주기
- 상태 저장과 불러오기(localStorage)
